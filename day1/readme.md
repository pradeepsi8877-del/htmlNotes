iweb development 
web development means creating a website or web application that can be accessed through the internet.
there are three types of web development
1. Frontend development
2. Backend development
3. Full-Stack development

Technology used 
1. Frontend development :- Html5, CSS3, JavaScript,React, Bootstrap, Tailwind CSS
2. Backend development :- Node.js, Express.js, MongoDB, MySQL,
3. Full-Stack development :- Combines both frontend and backend technologies

What is website
website is a collection of web pages .every website has a unique url.
webpages like homepage , aboutus, profile etc.

How website work  
when a user enter a browser and type a website URL, the browser sends a request to the server where the website is hosted. The server processes the request and sends back the requested web page to the browser, which then displays it to the user.

Frontend -> frontend development is a technology where user itract with the user interface of the website. It includes HTML, CSS, JavaScript, React, Bootstrap, Tailwind CSS.

backend -> backend development is a technology where the server-side of the website is developed. It includes Node.js, Express.js, MongoDB, MySQL.


Libraries -> libraries are pre-written code that developers can change manually. 
ex.-> react, tailwind css
 frameworks-> frameworks are the pre-written code that helps developers to build web applications faster and more efficiently.where user not change the code manually.
 ex.-> bootstrap, express.js

vs code -> vs code is code editor that is used to write code ,where user edit run and debug the code. it is free and open source software.

github :-github is a cloud plateform that is used to store and manage code repositories. it allows developers to collaborate on projects.

git :- git is a version control system that allows developers to track changes in their codebase and collaborate with other developers. it helps to manage different versions of code and resolve conflicts.

cloud Platforms -> Vercel , Netlify, lotify
Ai tools ->claude, cursor, chatgpt , etc.
